# 高数叉乘讲解网站 - 产品需求文档

## 1. 产品概述

一个交互式教育网站，通过动画和可视化方式讲解向量叉乘（Cross Product）的概念、几何意义和计算方法。

- **主要目的**：帮助学生直观理解向量叉乘的数学原理和几何意义
- **解决的问题**：传统教材中叉乘概念抽象，难以建立几何直觉
- **目标用户**：高等数学学习者、工科学生、对线性代数感兴趣的学习者
- **产品价值**：通过动画演示将抽象概念具象化，提升学习效率和理解深度

## 2. 核心功能

### 2.1 功能模块

1. **首页**：叉乘概念介绍、几何意义动画演示、右手定则可视化
2. **计算方法页**：叉乘计算公式推导、行列式表示法、坐标计算步骤
3. **例题练习页**：三道典型例题，包含详细解题步骤和动画验证

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 概念介绍区 | 叉乘定义、数学符号、基本性质 |
| 首页 | 几何意义动画 | 3D动画展示叉乘结果向量的方向、模长与两向量夹角的关系 |
| 首页 | 右手定则演示 | 交互式右手定则动画，可旋转视角观察 |
| 计算方法页 | 公式推导 | 从定义到行列式计算的完整推导过程 |
| 计算方法页 | 计算步骤 | 分步展示叉乘计算流程，高亮关键步骤 |
| 例题练习页 | 例题1 | 基础计算题：给定两向量求叉乘 |
| 例题练习页 | 例题2 | 几何应用题：求垂直于两向量的单位向量 |
| 例题练习页 | 例题3 | 综合应用题：计算平行四边形面积 |

## 3. 核心流程

用户访问网站后，按照以下流程学习：

1. 进入首页，通过动画直观理解叉乘的几何意义
2. 学习计算方法，掌握叉乘的坐标计算公式
3. 通过三道例题巩固知识，每道题都有详细的动画验证

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝渐变（#1e3a8a → #3b82f6）配合亮黄色强调（#fbbf24）
- **辅助色**：白色背景、深灰文字（#1f2937）
- **按钮样式**：圆角矩形，带轻微阴影和悬停动画
- **字体**：标题使用思源黑体 Bold，正文使用思源宋体，数学公式使用 KaTeX 渲染
- **布局风格**：卡片式布局，左侧导航 + 右侧内容区
- **图标/动画**：使用 Three.js 创建 3D 向量动画，配合 CSS 过渡效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | 概念介绍区 | 大号标题、定义卡片、数学符号高亮 |
| 首页 | 几何意义动画 | 3D 场景：可旋转的向量 a、b 和结果向量 a×b，实时显示模长和角度 |
| 首页 | 右手定则 | 3D 手部模型动画，拇指、食指、中指分别标注 i、j、k 方向 |
| 计算方法页 | 公式推导 | 逐步展开的公式卡片，带箭头指示推导方向 |
| 计算方法页 | 计算步骤 | 分步卡片，每步带高亮背景和动画过渡 |
| 例题练习页 | 例题卡片 | 题目区、解题步骤区、3D 验证动画区，三栏布局 |

### 4.3 响应式设计

- **桌面端优先**：最小宽度 1280px，三栏布局
- **平板适配**：768px - 1279px，两栏布局，3D 画布自适应
- **移动端**：< 768px，单栏布局，3D 动画简化为 2D 示意图
- **触摸优化**：移动端支持手势旋转 3D 场景

### 4.4 3D 场景指导

- **环境**：深色渐变背景（#0f172a → #1e293b），营造科技感
- **光照**：环境光 + 两盏方向光，营造立体感
- **相机**：透视相机，支持轨道控制（OrbitControls），可旋转缩放
- **构图**：向量起点置于原点，使用不同颜色区分（a: 红色，b: 蓝色，a×b: 绿色）
- **交互**：鼠标悬停显示向量坐标，点击切换显示/隐藏辅助线
- **动画**：向量生长动画、叉乘结果生成动画、右手定则演示动画
- **后处理**：轻微泛光效果（Bloom），突出向量线条
